<!-- What's new since the last release, for players, in plain English: one "- " line per change. tools/release.sh puts this in the release and empties it. -->
- On Mac, the very first match no longer stutters while its graphics get ready: they are prepared in the menu, as on later runs.
- OpenTennis now runs on Apple Silicon Macs (M1 and later): open the .dmg from the release page and drag OpenTennis onto Applications.
- VSync is now on by default, for a steady frame rate without tearing; choosing a graphics preset no longer turns it off.
