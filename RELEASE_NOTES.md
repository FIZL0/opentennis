- Online matches no longer fall out of sync when the weather changes during a match.
- Online, small differences in the crowd, ambient sounds or the sun's glare between the two machines can no longer throw a match out of sync.
- Beta builds now download from beta.opentennis.dev/download instead of the GitHub releases list, so launchers only offer real releases.
