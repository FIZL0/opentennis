<!-- What's new since the last release, for players, in plain English: one "- " line per change. tools/release.sh puts this in the release and empties it. -->
- iPhone and iPad: with no disc yet, the start screen now has a "Choose disc" button that opens the Files app, so the ISO can come from iCloud Drive, a USB drive or anywhere else; putting it in the OpenTennis folder still works too.
- The phone start screen now looks like the main menu, with a Help page and a progress bar while the disc is copied.
- Desktop: the first-start disc picker is now your system's own file dialog (it also works on Windows and macOS now).
- The highlighted button on the main menu now gently pulses in and out.
