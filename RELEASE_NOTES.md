<!-- What's new since the last release, for players, in plain English: one "- " line per change. tools/release.sh puts this in the release and empties it. -->
- Phones no longer dim and lock the screen during a match, even while it's paused; menus and the background still let the phone sleep as usual.
- After a match, the stats move aside for three choices: Rematch (the same match again), New Match (back to character select with everyone's picks kept) or Return to the Menu; online, Rematch starts once everyone is ready, or go Back to Lobby.
- The pause menu has Save and Quit: it keeps your match and takes you to the main menu, and the match will pick up at the start of the point you left. In online matches only the host has it.
- The main menu has a Continue card that picks up a saved match where you left it, showing the score and who's serving; with several matches saved, a Continue screen lists them to resume or delete.
